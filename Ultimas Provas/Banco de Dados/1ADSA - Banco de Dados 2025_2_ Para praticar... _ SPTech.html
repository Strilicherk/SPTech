Sistema de Controle de Acesso a Cursos Online

📘 Contexto:

A Faculdade XYZ está desenvolvendo um sistema simples para gerenciar o acesso de seus alunos aos cursos online. Cada aluno pode se inscrever em vários cursos, e cada curso pode ter vários alunos. Quando os alunos acessam a plataforma, o sistema registra a data e a duração do acesso.

Você foi contratado para modelar e consultar o banco de dados deste sistema utilizando MySQL. A estrutura de tabelas já foi definida (ver abaixo), e seu objetivo é criar consultas SQL para atender às demandas da coordenação.

🗃️ Estrutura do Banco:

  • Aluno(id_aluno, nome, email)

  • Curso(id_curso, nome_curso, descricao)

  • Aluno_Curso(id_aluno, id_curso, data_inscricao) — relacionamento N:N

  • Acesso(id_aluno, id_curso, data_acesso, duracao_minutos) — entidade fraca (chave composta)

🧪 Atividades — Total: 10 Itens

Parte 1 – Compreensão e Manipulação de Dados

  1. Listar todos os alunos e os cursos em que estão inscritos.

    • Dica: JOIN entre Aluno, Aluno_Curso e Curso.

  2. Exibir todos os acessos feitos pela aluna “Ana Silva”, com data e duração.

  3. Listar os cursos que têm mais de 1 aluno inscrito.

    • Dica: Use COUNT() e GROUP BY.

  4. Exibir a duração média dos acessos em cada curso.

    • Dica: Use AVG() agrupando por curso.

  5. Mostrar o total de minutos acessados por cada aluno em cada curso.

    • Dica: SUM(duracao_minutos) com GROUP BY.

Parte 2 – Views e Análises

  1. Criar uma VIEW chamada vw_total_acessos que contenha:

    • id_aluno, nome do aluno, id_curso, nome do curso, total de minutos acessados.

    • Dica: Combine JOIN, SUM, GROUP BY.

  2. Criar uma VIEW chamada vw_estatisticas_curso com:

    • id_curso, nome_curso, quantidade de alunos inscritos, tempo médio de acesso por curso.

  3. Exibir os 3 alunos com mais tempo total de acesso (em minutos).

    • Dica: ORDER BY SUM(duracao_minutos) DESC LIMIT 3.

  4. Listar os cursos que nunca foram acessados.

    • Dica: Use LEFT JOIN entre Curso e Acesso.

  5. Mostrar a quantidade de acessos por data, agrupando por dia.

    • Dica: Use DATE(data_acesso) e COUNT().
